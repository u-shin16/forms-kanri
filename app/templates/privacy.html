プライバシーポリシー

最終更新日：2026年8月25日

1. 適用範囲

本ポリシーは、u-shinが提供する「{{ APP_NAME }}」（Googleフォームの問い合わせ一括管理アプリ）に適用されます。{{ APP_NAME }}はRakuYadeブランドの一部として提供されていますが、Google認証・Googleフォームのデータを扱う都合上、本アプリ専用のポリシーとして定めます。運営者に関する共通情報は運営者情報ページもあわせてご確認ください。

2. 取得する情報

  • Googleアカウントの氏名・メールアドレス・プロフィール画像
  • Google Forms APIを通じて取得する、利用者が登録したフォームの質問内容・回答データ
  • アクセス解析情報（Google Analytics、測定ID：G-VT013GDMVN）
  • サーバーログ（IPアドレス、アクセス日時、エラー内容等。不具合調査・不正アクセス対策のため）

フォームの回答データには、利用者ご本人だけでなく、そのフォームに回答した第三者の氏名・連絡先等の個人情報が含まれる場合があります。フォームを管理する利用者は、回答者に対する個人情報保護法上の責任についてもご自身で確認・対応してください。

3. Google APIのスコープ（権限範囲）

Googleアカウント連携時に要求する権限は、必要最小限の以下のみです。

  • openid / userinfo.email / userinfo.profile：本人確認・アカウント表示のため
  • forms.body.readonly：フォームの質問内容を取得するため（閲覧のみ）
  • forms.responses.readonly：フォームの回答を取得するため（閲覧のみ）

いずれも読み取り専用の権限であり、{{ APP_NAME }}がフォームの作成・編集・削除・回答の送信を行うことはありません。

4. 保存先と保存方法

取得した情報はGoogle Cloud Firestore（Googleのクラウドデータベース）に保存します。Google認証のアクセストークンは、平文のまま保存せず、暗号化した状態で保存しています。

5. データの保護措置

フォームの回答には、回答した第三者の氏名や連絡先といった機微な情報が含まれることがあります。{{ APP_NAME }}では、これらを保護するために次の措置をとっています。

  • 通信の暗号化：ブラウザとサーバー間の通信、およびサーバーとGoogle APIの間の通信は、すべてTLS（HTTPS）で暗号化しています。暗号化されていない接続でアクセスされた場合は、暗号化された接続へ転送します。
  • 保存時の暗号化：データの保存先であるGoogle Cloud Firestoreは、保存されたデータをGoogleが管理する鍵で暗号化します。加えてGoogle認証のアクセストークンは、Firestoreへ書き込む前にアプリ側でも暗号化しており、平文では保存していません。
  • 利用者ごとの分離：管理フォーム・回答・メモ・対応状況は、Googleアカウントごとに分けて保存しています。ある利用者のデータを、別の利用者が閲覧・取得することはできません。
  • アクセスできる人の限定：本番環境のデータベースとサーバーへアクセスできるのは、運営者本人のみです。サーバーへの接続には公開鍵認証を使用しています。
  • セッションの保護：ログイン状態を保持するCookieには、HTTPS経由でのみ送信する設定と、JavaScriptから読み取れない設定を適用しています。あわせてフォーム送信にはCSRF対策を行っています。
  • 要求する権限の最小化：Googleに要求する権限は読み取り専用のものだけで、Googleドライブ全体を参照する権限は要求しません。フォームは利用者が編集画面のURLを登録したものだけを対象とします。
  • 保持するデータの最小化：利用目的に必要な範囲を超えてデータを保持しません。利用者がアカウントを削除すると、保存済みの管理フォーム・回答・メモ・設定をすべて削除します。
  • 不正アクセスへの備え：サーバーログを記録し、不審なアクセスや障害の調査に用います。データの取り扱いに関わる不具合を確認した場合は、対象となる利用者へお問い合わせ先を通じて連絡します。

6. Google APIから取得した情報の取り扱い（Limited Use）

{{ APP_NAME }}がGoogle APIから受け取った情報の使用および他アプリへの移転は、Google API Services User Data Policy（Limited Useの要件を含む）に準拠します。

{{ APP_NAME }}’s use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

具体的には、次のことを行いません。

  • 取得した情報を、広告の配信や広告のターゲティングに利用すること
  • 取得した情報を、データ仲介事業者・情報販売事業者その他の第三者へ販売または提供すること
  • 取得した情報を、汎用的なAI・機械学習モデルの開発・改善・学習に利用すること。フォームの質問内容および回答を、人工知能モデルの学習データとして使用したり、そのために第三者へ提供したりすることはありません。
  • 人間が取得した情報を閲覧すること。ただし、利用者から明示的な同意を得た場合、セキュリティ上の調査や法令遵守のために必要な場合、および情報を集計して個人を識別できない形にした場合を除きます。

7. 利用目的

  • 複数のGoogleフォームへの問い合わせを一覧化し、確認・対応状況の管理を行うため
  • 不具合の調査、お問い合わせへの対応のため
  • サービスの利用状況の把握、改善のため

取得したフォームの回答データは、利用者ご本人の管理画面にのみ表示し、第三者と共有することはありません。

8. 情報の保持期間・削除

取得した情報は、アカウントが存在する間保持します。設定画面の「アカウントを削除」を実行すると、本アプリに保存した管理フォーム・回答・設定を含むすべてのデータを削除します。この操作は取り消せません。

Googleアカウント側との連携自体は、Googleアカウントの「サードパーティ製アプリとサービス」の管理画面からもいつでも解除できます。

9. 第三者提供

法令に基づく場合を除き、取得した情報を本人の同意なく第三者へ提供することはありません。

10. 本ポリシーの変更

本サービスの内容や法令の変更に応じて、本ポリシーを改定することがあります。重要な変更がある場合は、本ページの更新日を変更してお知らせします。

11. お問い合わせ

情報の取り扱いに関するご質問・開示・削除のご依頼は、お問い合わせフォームからご連絡ください。
